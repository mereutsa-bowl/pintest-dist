# pintest-dist — раздача PinTest (тест)

Только дистрибутив, **без исходного кода** (код — в приватном `pintest-project`).

- `license.json` — публичный манифест версий и ссылки на APK, без списка Device-ID (D-309).
- APK — в Releases.

Версии и APK публикует владелец. Приватный реестр устройств не хранится в этом репозитории.

Современный dist-клиент проверяет регистрацию отдельно от публичной политики версий.
Удаление списка не отменяет регистрацию и обязательное обновление.

Этот PR мержить только в момент раздачи 364 после GO владельца. Версии и APK URL
в этом PR не меняются. Старые клиенты, читающие список устройств, могут потерять
доступ: до merge требуется отдельное подтверждение совместимости раздачи.
Основной URL `https://smartbowling.ru/pintest/license.json` обслуживается отдельно;
merge в этом репозитории сам по себе не меняет основной URL.

Проверка публичного контракта: `python3 -m unittest discover -s tests -v`.
Регрессия фактических Android-гейтов находится в `pintest-project`:
`DistTesterAdmissionTest` (допуск зарегистрированного, отсутствие обхода регистрации
и минимальной версии). Этот репозиторий не собирает и не подписывает Android APK.
